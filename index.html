🧵 ThreadLocal 实现内幕

全局共享 vs 线程私有 · 开放寻址 · 黄金分割哈希

🌐 全局共享 Map 早期设计
  • 单个 ThreadLocal 持有全局 Map<Thread, T>
  • 所有线程用同一张表，Key 为线程引用
  • 多线程读写 必须加锁 / CAS
  • 线程死亡后，Entry 仍残留在 Map 中 → 可能内存泄漏
⚠️ 全局竞争 + 跨核 Cache 乒乓
🧩 线程私有 Map JDK 8+
  • 每个线程持有自己的 ThreadLocalMap
  • Key 为 ThreadLocal 实例，Value 为存储值
  • 零同步：各线程只读自己的 Map
  • 线程死亡 → 整个 Map 及 value 一次性回收
  • 访问路径：currentThread().threadLocals，一次字段读取
✅ 无锁、缓存友好、生命周期自然绑定
📊 设计对比流程图
flowchart LR
    subgraph Global["全局共享 Map"]
        direction TB
        TL[ThreadLocal 实例] --> GMap[全局 Map]
        GMap --> |Thread-1| V1[value1]
        GMap --> |Thread-2| V2[value2]
        GMap --> |Thread-N| VN[valueN]
    end

    subgraph ThreadLocal["线程私有 Map"]
        direction TB
        T1[Thread-1] --> M1[ThreadLocalMap]
        M1 --> |TL实例| A[value1]
        T2[Thread-2] --> M2[ThreadLocalMap]
        M2 --> |TL实例| B[value2]
        TN[Thread-N] --> MN[ThreadLocalMap]
        MN --> |TL实例| C[valueN]
    end
🔍 开放寻址 + 线性探测 Open Addressing
  • 不使用 红黑树或链表（Entry 数量预期极少）
  • 冲突后顺数组向后找空槽，缓存行友好，优于指针追溯
  • Entry 结构轻量，无额外指针开销

⚡ 零同步 · 缓存友好
  • 线程只读自己的 Map，不存在竞争路径
  • 若用全局 Map<Thread,T>，则必须加入并发控制（锁/CAS）
  • 访问路径仅 currentThread().threadLocals，无哈希查找
  • 避免跨核缓存一致性开销
♻️ 生命周期 · 内存安全
  • 线程死亡 → Thread 对象不可达 → 整个 Map 及所有 value 一次性回收
  • 数据生命周期天然绑定线程，而非绑定可能永生的静态字段
  • 消除手动清理 remove() 的遗忘风险
⚡ 基于 JDK 8+ ThreadLocal 实现  ·  可视化仅供学习参考

数据库撕裂

June 01, 2026
数据库

◀ 返回

1. 根源：扇区与页的大小错位

数据库以 页 (Page) 为单位思考（通常 16KB），硬盘却以 扇区 (Sector) 为单位存储（通常 512 字节）。
写入一个页需要依次写入 32 个连续扇区。如果在写入中途断电：

  • 前 17 个扇区：新数据 ✅
  • 第 18 个扇区：正在写入 → 数据损坏或未定义 💥
  • 后 14 个扇区：旧数据 🕒

结果：一个逻辑页在物理上变成了“新 + 坏 + 旧”的混合体 —— 页撕裂 (Torn Page)。

注：单个扇区的写入在硬件上具有原子性（要么全写对，要么全不写），但跨扇区无此保证。

2. 如何发现撕裂？页校验 (Page Checksum)

数据库在写入页前，会根据整个页内容计算一个 校验值 (Checksum) 并存入页头。
读取时重新计算并与页头比对：

  • 若页因撕裂而新旧混合 → 新校验值 几乎必然 ≠ 旧校验值
  • 数据库报错：Checksum mismatch，明确告知数据损坏。

3. 传统软件层解法：写两遍

硬件不提供跨扇区的原子性，数据库就在软件层做冗余。

3.1 MySQL / InnoDB：双写缓冲区 (Doublewrite Buffer)

  1. 脏页不直接写到最终位置。
  2. 先顺序写入一个专用区域 —— 双写缓冲区。
  3. 调用 fsync() 强制落盘。
  4. 再随机写回真实位置（B+Tree）。
  5. 崩溃恢复时：若真实页校验失败，从双写缓冲区拷贝完整副本覆盖。

代价：写放大 2 倍。
